# Créditos de fotografías

Las fotografías municipales proceden de Wikimedia Commons. El script `PREPARAR_MEDIA_LOCAL.ps1` permite almacenarlas localmente para evitar hotlinking en el despliegue. La atribución se conserva según la ficha exacta de cada archivo.
